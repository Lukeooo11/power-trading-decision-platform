# 全国电力交易辅助决策平台 · 公开脱敏版

长期访问地址：https://lukeooo11.github.io/power-trading-decision-platform/

此目录由 `power-trading-platform-upgrade/build-public-demo.mjs` 生成。

- 已接入山东2026年1至6月真实小时日前/实时价格和组合负荷。
- 已接入127家客户的19,459条日负荷与24点分时负荷记录。
- 已接入山东2026-05-01至2026-07-01的1488个完整小时GFS天气点；原始文件前置空白和不完整区间不补零。
- 业务确认目标交易前可获得D-1完整日前与实时结算价格；价格历史边界更新为D-1。电源实际出力仍按独立发布时间审计，不能沿用价格边界。
- 当前本地默认候选模型为 `sd-gfs24-d1-price-actual-supply-mixed-v5`：日前价格使用 XGBoost，实时价格和价差使用 LightGBM；三者使用已确认可得的D-1结算价及D-1实际负荷/风光出力特征。旧版 `sd-gfs24-d1-price-actual-supply-lgbm-v4`、`sd-gfs24-d1-settlement-lgbm-v3` 和 `sd-gfs24-actual-supply-lgbm-v2` 保留用于回退和对照。当前提交已在本地完成，GitHub 推送需网络恢复后触发线上发布。
- 业务方确认天气均在对应交易日申报前可得；线上默认模型为 `sd-target-supply-conditional-v1`：目标日24点供需预测完整时使用供需条件增强模型，否则自动回退六天气特征与滞后信息模型；精确forecast_issue_time仍待补充。
- 已接入山东Q1实际出力与Q2预测出力共4344个小时点；模型仅使用Q2的D-1/D-7滞后值，目标日预测和发布时间仍待补。
- 已接入1至6月687条客户月度结算记录；当前只确认表内结算毛利，公司净利润待补财务数据。
- 客户真实名称均替换为稳定代号；名称映射、户号、计量点和内部哈希不进入公开仓库。
- 页面用于辅助分析和人工复核，不构成自动交易指令。
- 已接入128家脱敏零售套餐（113家标准化、15家双边协商）以及2026年1至6月日级中长期持仓；月度覆盖率、剩余敞口和历史成本情景仅供人工复核，不生成24点/96点申报。
- 线上预测快照为 `data/price-forecast-history.json`，覆盖2026-05-15至2026-07-31；目标日供需增强版本和回退版本均保留在后端受控模型资产中。
- 预测输出同时包含日前、实时、价差的P10/P50/P90和单日回测指标；事件分数不是校准概率，不代表自动交易策略；合同、持仓、申报和限额不完整时策略保持HOLD。
