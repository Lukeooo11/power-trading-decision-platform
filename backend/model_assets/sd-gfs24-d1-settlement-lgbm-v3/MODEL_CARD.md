# 山东 D-1 结算价增强 LightGBM v3

## 训练口径

- 交易市场：山东，售电侧价格预测。
- 训练截止：2026-06-30；2026-07-01至2026-07-31为冻结独立测试。
- 日前、实时、价差点预测及负价/尖峰事件头均使用 LightGBM。
- 新增信息：目标交易前可获得的 D-1 日前和 D-1 实时结算价格，以及相应事件滞后特征。
- 电源出力：仍只使用 48 小时及以上滞后特征，未使用目标日实际出力。
- 天气：16市 GFS 提前24小时预报，保留发布时间和有效时间审计。

## 使用限制

本模型只输出预测和风险提示，不产生交易终端订单。电源出力的正式发布时间仍需独立核验；若无法证明目标日前可得，不能把目标日或同日实际出力作为输入。
